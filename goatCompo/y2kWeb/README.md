# HYBRIDFORMULA.COM — Local Setup

## วิธีที่ 1: Dev Mode (แนะนำ)
```bash
npm install
npm run dev
```
แล้วเปิด http://localhost:5173

## วิธีที่ 2: Preview build สำเร็จรูป
```bash
npm install
npm run preview
```
แล้วเปิด http://localhost:4173

## วิธีที่ 3: ใช้ dist โดยตรงด้วย serve
```bash
npx serve dist
```
แล้วเปิด http://localhost:3000
