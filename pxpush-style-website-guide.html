Nº001 / What Kind of Site

SINGLE
LONG
SCROLL.

PX PUSH is a single-long-scroll marketing site for a design-subscription service. Unlimited design requests for a flat monthly fee. The whole page does one job: convert visitors into "Get Started" clicks. Everything — copy, layout, motion — is in service of that.

Site map is intentionally tiny:

/ — Home (does 90% of selling) /about /journal — blog /start — signup / CTA landing /terms /privacy
02
Nº002 / Visual & Interaction Style

Five Defining
Traits

Trait 01 / Canvas
Near-Black
Background

Near-black (#1a1a1a) with off-white text. High contrast, moody, editorial. Every other colour becomes accent-level loud against this base.

Trait 02 / Type
Oversized
Display Type

Section titles repeat 6–8× stacked or marqueeing — a classic looping marquee used purely for visual rhythm. Bebas Neue or similar condensed display face at 10–14vw.

Trait 03 / Labels
Numbered
Section Labels

"Nº001 / Intro", "Nº002 / Works" — gives an editorial, catalog/index feel. Bullet dots (●) as recurring graphic motif before headings and nav items.

Trait 04 / Motion
Horizontal
Marquees

Full-bleed autoplay looping video for hero. Horizontal/looping image marquees for portfolio and brand assets. Continuous motion = never feels static.

Trait 05 / Copy
Sparse, Punchy
Paragraphs

Arrows (↗) on every CTA. Short sentences, active voice. Concrete numbers everywhere — "$4,000/mo", "72 hour delivery" — specificity builds trust more than vague claims.

Nº004 / Recommended Stack

Two
Options.

A
No-Code — Fastest

Framer or Webflow handle scroll animation, marquees, and CMS with zero custom code. PX PUSH likely uses one — they sell Framer/Webflow dev as a Pro package feature.

B
Custom Code — Full Control

Vite + HTML/CSS/JS or Next.js. GSAP + ScrollTrigger for scroll reveals and horizontal pinning. Lenis for smooth inertia. Tailwind for styling velocity.

05
Nº005 / Building Each Section

Section
Recipes.

01
Hero

Full-viewport <video> muted autoplay loop + dark overlay. Repeating h1 with CSS marquee. Scroll-cue anchored bottom.

02
Portfolio Marquee

Flex container wider than viewport. Duplicate image set, animate translateX infinite. Pause on hover. .webp throughout.

03
Benefits

Numbered Nº001–Nº005. Short headline + 1–2 sentence description. ScrollTrigger stagger 0.08s per item.

04
Pricing Cards

Plan name, strikethrough + discounted price, feature list, single CTA. Mark one "Popular". 2–3 tiers max.

05
Upsell

Same card pattern but framed as a fixed-scope project. Captures leads not ready to commit monthly.

06
Footer

Legal entity + address, social links, secondary CTA, legal pages. Never skip the address — trust signal.

06
Nº006 / Copywriting Patterns

Words That
Convert.

Pattern 01

Problem →
Reframe → Offer

Name the pain of hiring designers/freelancers/agencies. Reposition the subscription as the fix. Never lead with features — lead with the friction you remove.

Pattern 02

Concrete
Numbers

"$4,000/mo", "72 hour delivery", "4 weeks" — specificity builds trust more than vague claims. Every CTA uses ↗ and action verbs: "Get Started", "View Pricing".

07
Nº007 / Performance & Technical Notes

Ship
Fast.

Compress hero video aggressively — target <3–5 MB. Provide poster frame for slow connections.
Use .webp / .avif for all imagery. Lazy-load below-the-fold marquee images.
Load GSAP + Lenis deferred/async — don't block first paint.
Respect prefers-reduced-motion — disable marquees and scroll-jacking for users who request it.
Keep to one route (/) with anchor links — reduces build complexity, keeps funnel linear.
Target Core Web Vitals: LCP <2.5 s, CLS <0.1, INP <200 ms.

Nº008 / Minimal Build Checklist

11 Steps
to Ship.

Set up Next.js / Vite or Framer / Webflow. Dark theme tokens — #1a1a1a bg, off-white text.
Build hero: video bg + marquee headline component (reusable — you will use it 3× on the page).
Build reusable Section wrapper with "Nº00X / Label" eyebrow pattern.
Build horizontal image-marquee component (reuse for Works + Brand assets).
Build Benefits list: icon + numbered title + copy, ScrollTrigger stagger.
Build Pricing card component (reuse for Standard / Pro / Brand Sprint).
Wire up scroll animations — GSAP ScrollTrigger for fade/slide-ins.
Add smooth scroll — Lenis if going custom-code.
Build footer with legal entity + address + socials + secondary CTA.
Add /about, /journal, /start, /terms, /privacy as simpler secondary pages.
Optimize media, test prefers-reduced-motion, test mobile.
