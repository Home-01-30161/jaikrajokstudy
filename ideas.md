# JaiKrajok - กระจกสะท้อนใจ Design

## Three Approaches

### 1. Vintage Collage / Halftone Print Shop
- Very brief: Cream graph paper backgrounds with realistic black-and-white photo collage elements treated with halftone dot screen-printing effects. Checkerboard borders, red star accents, hand-drawn feel.
- Probability: 0.92

### 2. Modern Glassmorphism
- Very brief: Frosted glass panels on soft gradient backgrounds with subtle depth and blur effects.
- Probability: 0.04

### 3. Retro Zine / Risograph
- Very brief: Bold offset-printed colors, misaligned registration marks, and paper grain textures.
- Probability: 0.03

## Chosen: Vintage Collage / Halftone Print Shop

### Design Movement
Inspired by vintage screen-printed zines, halftone newspaper clippings, and student scrapbook collage aesthetics.

### Core Principles
1. Realistic photo collage elements with halftone dot treatment (no vector art)
2. Graph paper grid as foundational background texture
3. Checkerboard black & white as border/accent element
4. All black UI components use curved/rounded edges

### Color Philosophy
- Primary bg: Cream/beige (#F5F0E8) — warm, inviting, paper-like
- Black (#1A1A1A): UI elements, sidebar — always curved
- Dark teal (#2D6A6F): Primary action buttons
- Red (#C41E3A): Accent sparks, decorations
- Pink/Salmon (#FFB5A7): Highlights, badges, branding
- White (#FFFFFF): Cards, content surfaces

### Layout Paradigm
- Full-screen app with black curved sidebar on left
- Checkerboard strip at very top
- Large cream content area with graph paper grid
- Collage elements scattered as decorative accents

### Signature Elements
1. Halftone dot patterns (varying density, decorative)
2. Realistic collage photos (hand with pen, glasses, stationery, chat bubbles)
3. Black diagonal curved shapes as page dividers

### Interaction Philosophy
Snappy transitions, organic-feeling hover states, elements that feel like paper being moved around.

### Animation
- Subtle parallax on collage elements
- Smooth page transitions (200-300ms)
- Sidebar items slide in on hover
- Button press: scale(0.97) with ease-out

### Typography System
- Display: Playfair Display (serif, bold headings)
- Body: Noto Sans Thai (clean, readable Thai text)
- Monospace accents: Space Mono (for labels, badges)

### Brand Essence
**A warm mirror for student wellbeing** — for Thai high schoolers navigating emotional challenges, offering a safe space to see themselves clearly through the lens of compassionate AI.

**Personality:** Warm, honest, grounded

### Brand Voice
- Headlines feel like a caring friend speaking directly to you
- CTAs are encouraging, never pushy
- Example 1: "พื้นที่ปลอดภัยให้ใจได้มองเห็นตัวเอง"
- Example 2: "เริ่มต้นใช้งาน"

### Wordmark & Logo
Rounded, friendly letterforms with a subtle reflection/mirror motif in the "ค" character. Pink/salmon on dark teal or black background.

### Signature Brand Color
**Salmon Pink (#FFB5A7)** — warm, human, distinctive

## Style Decisions
- All black components MUST use border-radius (curved edges), never sharp corners
- Graph paper grid is the default page background
- Halftone dot patterns serve as decorative background texture
- Checkerboard strip appears at top of login and main app pages
- Collage elements are positioned as scattered decorative accents, not centered icons
