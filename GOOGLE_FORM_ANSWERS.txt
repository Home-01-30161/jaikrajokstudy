ตัวอย่าง:
- GET /health  -> เช็คระบบ + ฐานข้อมูล
- POST /webhooks/line -> Webhook LINE Bot
- POST /thaillm/v1/chat/completions -> แชทด้วย ThaiLLM-8b
- POST /typhoon/v1/chat/completions -> Typhoon (OCR)
- POST /ptm-asr/audio/transcriptions -> เสียงเป็นข้อความ
- POST /ssense -> วิเคราะห์อารมณ์
- POST /search -> ค้นหาเว็บ
- GET /user-data/export -> ส่งออกข้อมูลผู้ใช้ (PDPA)
ทดสอบด้วย curl: curl https://team07.aiforthai.in.th/api/health

ข้อ 5) มี API Key/Auth และตั้งค่า Security เรียบร้อย
--------------------------------------------------------
- LINE Signature verification (HMAC-SHA256) ทุก webhook -> signature ผิด = 401
- Rate limiting (120 req/15นาที/IP, 10 req สำหรับ endpoint แพง)
- Admin dashboard /admin-db ป้องกันด้วย ADMIN_SECRET
- เข้ารหัสข้อมูลผู้ใช้ AES-256-GCM + hash line_user_id
- PDPA: ผู้ใช้ส่งออก/ลบข้อมูลได้ (/user-data/export, DELETE /user-data)
- Security headers: CSP, HSTS, nosniff, frame-ancestors
- API keys เก็บใน GitLab CI/CD Variables (APP_*) ไม่มีใน repo

ข้อ 7) ระบบเสถียร ไม่ล่มระหว่างทดสอบ
--------------------------------------------------------
- Healthcheck ทุก 15 วินาที + restart อัตโนมัติ (unless-stopped)
- /health เช็คฐานข้อมูลด้วย (SELECT 1) - จับ migration พังได้ทันที
- AI upstream มี retry + backoff (Typhoon 2 ครั้ง, ThaiLLM 502/503 retry)
- timeout 30-40 วิ สำหรับวิเคราะห์รูป
- Log จำกัดขนาด 50MB ป้องกัน disk เต็ม
- migration แบบ guarded รันใน transaction
- ระหว่างพัฒนาพบปัญหา 2 จุดที่ทำให้ล่ม (migration 002, API timeout)
  -> จับได้โดย pipeline/local test แก้และ deploy แล้ว
