ชื่อโครงงาน: กระจกสะท้อนใจ (JaiKrajok): AI Emotion-Aware Study Buddy

ประเภทโครงงาน: สาขาคอมพิวเตอร์

ผู้จัดทำโครงงาน: 1. นายปองชัย บุณยวรรณ์ 2. นางสาวกนิษฐา หอมนาน 3. นางสาวพิชญธิดา ประสมทรัพย์

โรงเรียน: โรงเรียนเพชรพิทยาคม อำเภอเมือง จังหวัดเพชรบูรณ์ (ปีการศึกษา 2569)

การพัฒนาโครงงาน “กระจกสะท้อนใจ (JaiKrajok): AI Emotion-Aware Study Buddy” มีวัตถุประสงค์เพื่อศึกษาปัญหาและความต้องการด้านสุขภาวะทางอารมณ์ของนักเรียน, ออกแบบและพัฒนาระบบผู้ช่วยด้านการเรียนรู้และสุขภาวะทางอารมณ์ โดยประยุกต์ใช้เทคโนโลยีปัญญาประดิษฐ์ AI for Thai และ Pathumma LLM ในการวิเคราะห์อารมณ์จากใบหน้า ข้อความ และเสียง พร้อมทั้งให้คำแนะนำที่เหมาะสมกับผู้ใช้งาน และทดสอบประสิทธิภาพและศึกษาความพึงพอใจของผู้ใช้งานที่มีต่อระบบ กลุ่มเป้าหมายที่ใช้ในการทดลอง ได้แก่ นักเรียนชั้นมัธยมศึกษาปีที่ 6/1 โรงเรียนเพชรพิทยาคม ที่เข้าร่วมทดลองใช้ระบบ

ผลการดำเนินงานพบว่า ระบบสามารถวิเคราะห์สภาวะทางอารมณ์ของผู้ใช้งานจากข้อมูลหลายรูปแบบ ได้แก่ ภาพใบหน้า ข้อความ และเสียง พร้อมทั้งให้คำแนะนำที่เหมาะสมผ่าน Web Application ผู้ใช้งานสามารถติดตามสภาวะทางอารมณ์ของตนเอง มีพื้นที่ปลอดภัยในการระบายความรู้สึก และได้รับคำแนะนำที่ช่วยลดความเครียดจากการเรียน นอกจากนี้ ระบบยังสามารถช่วยอธิบายเนื้อหาจากเอกสารการเรียนผ่านเทคโนโลยี OCR และ Pathumma LLM ซึ่งช่วยส่งเสริมการเรียนรู้และเพิ่มความสะดวกในการใช้งาน ทั้งนี้ ระบบได้รับการออกแบบโดยคำนึงถึงความปลอดภัยของข้อมูลส่วนบุคคลตามหลักการคุ้มครองข้อมูลส่วนบุคคล (PDPA)

กิตติกรรมประกาศ

โครงงาน “กระจกสะท้อนใจ (JaiKrajok): AI Emotion-Aware Study Buddy” ฉบับนี้สำเร็จลุล่วงได้ด้วยความอนุเคราะห์และการสนับสนุนจากหลายฝ่าย คณะผู้จัดทำขอกราบขอบพระคุณคุณครูนาจรี ถือศิลป์และคุณครูสราวุธ สิงห์โตทอง ครูที่ปรึกษาโครงงาน ที่ได้ให้คำปรึกษา ข้อเสนอแนะ และตรวจสอบแก้ไขข้อบกพร่องของโครงงานด้วยความเอาใจใส่ตลอดระยะเวลาการดำเนินงานตลอดจนเอื้อเฟื้อห้องปฏิบัติการและเครื่องมือต่างๆ ในการทำโครงงานนี้จนประสบความสำเร็จ และขอขอบพระคุณ โรงเรียนเพชรพิทยาคม คณะครู และนักเรียนชั้นมัธยมศึกษาปีที่ 6/1 ที่ให้ความร่วมมือ สนับสนุนข้อมูล และอำนวยความสะดวกในการจัดทำโครงงานครั้งนี้

ท้ายที่สุด คณะผู้จัดทำขอขอบพระคุณบิดา มารดา และครอบครัวของผู้จัดทำทุกท่าน ที่ให้การสนับสนุนและเป็นกำลังใจ จนทำให้โครงงานฉบับนี้สำเร็จลุล่วงด้วยดี

บทที่ 1 บทนำ

1.1 ที่มาและความสำคัญ

นักเรียนไทยกำลังเผชิญกับวิกฤตสุขภาวะทางอารมณ์ที่ถูกมองข้าม จากข้อมูลของกรมสุขภาพจิต กระทรวงสาธารณสุข พบว่าประมาณร้อยละ 20 ของประชากรไทย หรือประมาณ 13 ล้านคน มีปัญหาสุขภาพจิต แต่มีเพียงประมาณ 3 ล้านคนเท่านั้นที่เข้าถึงการช่วยเหลือ ในจำนวนนี้กลุ่มวัยรุ่นและเยาวชนอายุ 15-19 ปีเป็นกลุ่มที่มีความเสี่ยงสูงโดยเฉพาะนักเรียนระดับมัธยมศึกษาตอนปลายที่กำลังเผชิญกับความเครียดจากการสอบแข่งขัน การตัดสินใจเลือกเส้นทางการศึกษาเข้าสู่ระดับอุดมศึกษา และแรงกดดันจากครอบครัวและสังคม

ปัญหาสำคัญที่พบคือ นักเรียนจำนวนมากไม่ตระหนักรู้ถึงสภาวะทางอารมณ์ของตนเอง ขาดเครื่องมือที่จะช่วยสะท้อนให้เห็นว่าตนเองกำลังอยู่ในภาวะเครียดหรือมีแนวโน้มของอารมณ์เชิงลบที่ส่งผลกระทบต่อประสิทธิภาพการเรียนรู้ งานวิจัยด้านประสาทวิทยาการเรียนรู้ชี้ว่าสภาวะทางอารมณ์มีผลโดยตรงต่อความสามารถในการเรียนรู้และการจดจำ หากนักเรียนอยู่ในภาวะเครียดหรือวิตกกังวลสูง สมองจะไม่สามารถประมวลผลข้อมูลใหม่ได้อย่างมีประสิทธิภาพ การดูแลสุขภาวะทางอารมณ์จึงเป็นปัจจัยพื้นฐานที่ส่งผลต่อผลสัมฤทธิ์ทางการเรียน

ดังนั้นจึงมีความจำเป็นอย่างยิ่งในการพัฒนาเครื่องมือที่ช่วยให้นักเรียนตระหนักรู้ถึงสภาวะทางอารมณ์ของตนเอง มีพื้นที่ปลอดภัยในการระบายความรู้สึก และได้รับคำแนะนำที่เหมาะสมเฉพาะบุคคล โดยใช้เทคโนโลยีปัญญาประดิษฐ์ที่พัฒนาในประเทศไทยร่วมกับเทคโนโลยีจากต่างประเทศ เพื่อให้สอดคล้องกับบริบททางภาษาและวัฒนธรรมไทย

1.2 วัตถุประสงค์

  • 1.2.1 เพื่อออกแบบและพัฒนาระบบ “กระจกสะท้อนใจ (JaiKrajok): AI Emotion-Aware Study Buddy” สำหรับส่งเสริมสุขภาวะทางอารมณ์ของนักเรียน
  • 1.2.2 เพื่อประยุกต์ใช้เทคโนโลยี AI for Thai และ Pathumma LLM ในการวิเคราะห์อารมณ์จากใบหน้า ข้อความ และเสียง พร้อมให้คำแนะนำที่เหมาะสมกับผู้ใช้งาน
  • 1.2.3 เพื่อพัฒนาระบบที่สามารถช่วยอธิบายเนื้อหาจากเอกสารการเรียนผ่านเทคโนโลยี OCR และสนับสนุนการเรียนรู้ของนักเรียน
  • 1.2.4 เพื่อทดสอบประสิทธิภาพและประเมินความพึงพอใจของผู้ใช้งานที่มีต่อระบบ

1.3 ขอบเขตของการศึกษา

การออกแบบและพัฒนาระบบ “กระจกสะท้อนใจ (JaiKrajok): AI Emotion-Aware Study Buddy” ในรูปแบบ Web Application โดยประยุกต์ใช้เทคโนโลยี Pathumma LLM เป็น Text LLM ให้คำแนะนำที่เหมาะสมและช่วยอธิบายเนื้อหาจากเอกสารการเรียน มีการเรียกใช้ API จาก AI For Thai ได้แก่ Sentiment Analysis และ Typhoon ASR ซึ่งเป็นเทคโนโลยีที่ถูกพัฒนาในประเทศไทย นอกจากนี้ได้มีการนำ Gemini 1.5 Flash มาใช้เป็น Vision LLM โดยจะใช้ TypeScript เป็นภาษาหลักสำหรับ Frontend และ Backend ข้อมูลประวัติการแชทของผู้ใช้จะถูกเก็บไว้ที่ Local Storage บน Browser ของผู้ใช้ ซึ่งผู้ใช้สามารถส่งออกและลบได้ตลอดเวลา

กลุ่มเป้าหมายที่ใช้ในการทดลองระบบ ได้แก่ นักเรียนระดับมัธยมศึกษาปีที่ 6 จำนวน 29 คน ซึ่งเป็นผู้ทดลองใช้งานระบบเพื่อประเมินประสิทธิภาพและความพึงพอใจในการใช้งาน

1.4 สมมติฐาน

ระบบกระจกสะท้อนใจ (JaiKrajok): AI Emotion-Aware Study Buddy สามารถ Deploy บน Vercel และเรียกใช้ API ด้วย Vercel Serverless Function ได้อย่างสมบูรณ์ รวมถึงช่วยวิเคราะห์สภาวะทางอารมณ์ของผู้ใช้งานได้อย่างเหมาะสมและช่วยให้นักเรียนตระหนักรู้ถึงสภาวะทางอารมณ์ของตนเองได้ดีขึ้น

1.5 ตัวแปรที่ศึกษา

  • ตัวแปรต้น: การใช้งานระบบ JaiKrajok: AI Emotion-Aware Study Buddy
  • ตัวแปรตาม: ผลการวิเคราะห์สภาวะทางอารมณ์, ระดับความพึงพอใจของผู้ใช้งาน, การตระหนักรู้เกี่ยวกับสภาวะทางอารมณ์ของผู้ใช้งาน
  • ตัวแปรควบคุม: กลุ่มตัวอย่างเป็นนักเรียนชั้นมัธยมศึกษาปีที่ 6/1 โรงเรียนเพชรพิทยาคม ใช้ระบบ WebApp เดียวกัน

1.6 นิยามเชิงปฏิบัติการ

Artificial Intelligence: สาขาทางวิทยาศาสตร์และเทคโนโลยีคอมพิวเตอร์ที่มุ่งเน้นการพัฒนาระบบหรือซอฟต์แวร์ให้มีความสามารถในการคิด เลียนแบบพฤติกรรม เรียนรู้ วิเคราะห์เหตุผล และแก้ปัญหาได้คล้ายคลึงกับกระบวนการทางปัญญาของมนุษย์

Pathumma-ThaiLLM-qwen3-8b-think-3.0.0: โมเดลภาษาขนาดใหญ่ (Large Language Model) เฉพาะทางภาษาไทย ที่ได้รับการปรับแต่งและต่อยอดมาจากสถาปัตยกรรม Qwen3 มีขนาดพารามิเตอร์ 8 พันล้านพารามิเตอร์ (8B) โดยมีจุดเด่นในเรื่องของกระบวนการคิดวิเคราะห์อย่างเป็นระบบ (Thinking/Reasoning Capabilities)

Typhoon ASR: ระบบแปลงเสียงพูดเป็นข้อความอัตโนมัติ (Automatic Speech Recognition) เน้นการถอดความและจดจำเสียงพูดภาษาไทยเป็นหลัก

TypeScript & JSON: ภาษาโปรแกรมมิ่งที่เป็นส่วนขยายของ JavaScript พร้อมระบบจัดการประเภทข้อมูลแบบสถิต ร่วมกับรูปแบบการจัดเก็บข้อมูลโครงสร้างน้ำหนักเบา

บทที่ 2 เอกสารและงานวิจัยที่เกี่ยวข้อง

2.1 สถานการณ์สุขภาพจิตของนักเรียนและเยาวชนไทย

จากรายงานผลการสำรวจสภาวะทางอารมณ์และพฤติกรรมของวัยรุ่นไทยในปี 2568 จากกลุ่มตัวอย่างนักเรียนมัธยมศึกษาทั่วประเทศจำนวน 1,139 คน พบว่า สุขภาพจิตของวัยรุ่นไทยอยู่ในขั้นน่าเป็นห่วงอย่างมาก โดยร้อยละ 39.6 มีความเครียดกระทบต่ออารมณ์ในระดับมากถึงมากที่สุด และร้อยละ 60.1 มีความรู้สึกหมดไฟ (Burnout) ตั้งแต่ระดับปานกลางขึ้นไป นอกจากนี้ ในด้านโรควิตกกังวล พบผู้ที่มีอาการครบตามเกณฑ์วินิจฉัยร้อยละ 14.7 และร้อยละ 41.4 มีภาวะกลัวสังคม (Social Phobia)

2.2 ผลกระทบของความเครียดต่อการเรียนรู้และความจำ

ความเครียดมีอิทธิพลโดยตรงต่อการทำงานของระบบประสาทและสมอง โดยเฉพาะส่วนฮิปโปแคมปัส (Hippocampus) ซึ่งทำหน้าที่เกี่ยวกับการบันทึกความจำระยะยาว การจัดการความเครียดในระดับที่เหมาะสมจึงเป็นปัจจัยสำคัญในการเพิ่มประสิทธิภาพการเรียนรู้ของนักเรียน

2.3 Facial Emotion Recognition & Sentiment Analysis

การวิเคราะห์อารมณ์จากใบหน้าและข้อความใช้เทคโนโลยี Computer Vision ร่วมกับ Natural Language Processing (NLP) โดยโมเดล Deep Learning ยุคใหม่สามารถสกัดฟีเจอร์เชิงพื้นที่และบริบทภาษาไทย เพื่อให้ผลประเมินอารมณ์มีความแม่นยำสูง

2.4 เทคโนโลยีและแพลตฟอร์ม AI ที่ใช้

  • AI For Thai: แพลตฟอร์มบริการ API ปัญญาประดิษฐ์สัญชาติไทย โดย NECTEC
  • ThaiLLM & Pathumma LLM: โครงสร้างพื้นฐานโมเดลภาษาขนาดใหญ่ระดับชาติที่รองรับภาษาและวัฒนธรรมไทยอย่างลึกซึ้ง
  • Gemini 1.5 Flash: โมเดล Multimodal จาก Google รองรับการประมวลผลข้อความ ภาพ และ OCR ด้วยความเร็วสูง

บทที่ 5 สรุป อภิปรายผล และข้อเสนอแนะ

5.1 สรุปผลการดำเนินงาน

คณะผู้จัดทำสามารถพัฒนาระบบกระจกสะท้อนใจ (JaiKrajok) ในรูปแบบ Web Application ได้สำเร็จลุล่วงด้วยดี ระบบรองรับการประมวลผล Multimodal ทั้งข้อความ ภาพ และเสียง สามารถวิเคราะห์อารมณ์ ให้คำแนะนำ และอธิบายบทเรียนแก่นักเรียนได้อย่างมีประสิทธิภาพ ผ่านเกณฑ์มาตรฐานทางซอฟต์แวร์และความปลอดภัย PDPA

5.2 อภิปรายผล

การประยุกต์ใช้โมเดลภาษาไทยอย่าง Pathumma LLM และ AI For Thai ร่วมกับโมเดลระดับโลก ให้ผลลัพธ์ที่แม่นยำและตอบโจทย์บริบททางภาษาของวัยรุ่นไทยได้อย่างตรงจุด สอดคล้องกับสมมติฐานที่ตั้งไว้

5.3 ข้อเสนอแนะ

  • ควรปรับปรุงความรวดเร็วในการตอบสนองให้ดียิ่งขึ้นเมื่อมีผู้ใช้งานพร้อมกันจำนวนมาก
  • เพิ่มระบบการติดตามผลสุขภาวะทางอารมณ์ในระยะยาว (Longitudinal Emotion Tracking)
  • ขยายกลุ่มตัวอย่างการทดลองไปยังโรงเรียนอื่นๆ เพื่อเพิ่มความหลากหลายของข้อมูล
