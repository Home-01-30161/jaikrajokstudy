=== เฉลย (manual physics solution) ===

ข้อมูลที่กำหนด:
- ความเร็วต้น = u, ทำมุม 45 กับแนวดิ่ง
- ที่จุด A: ทำมุม 60 กับแนวดิ่ง
- g = ความเร่งโน้มถ่วง

วิธีทำ:

ขั้นตอนที่ 1: หาองค์ประกอบความเร็ว
มุม 45 กับแนวดิ่ง = 45 กับแนวราบ
- ux = u sin(45) = u/sqrt(2)  (แนวราบ, คงที่ตลอด)
- uy = u cos(45) = u/sqrt(2)  (แนวดิ่ง, ขึ้น)

ขั้นตอนที่ 2: ที่จุด A มุม 60 กับแนวดิ่ง = 30 กับแนวราบ
- vx_A = ux = u/sqrt(2)  (ไม่เปลี่ยน)
- tan(60) = vx_A / vy_A
  vy_A = vx_A / tan(60) = (u/sqrt(2)) / sqrt(3) = u/sqrt(6)

ขั้นตอนที่ 3: ใช้สมการ vy^2 = uy^2 - 2gH
- (u/sqrt(6))^2 = (u/sqrt(2))^2 - 2gH
- u^2/6 = u^2/2 - 2gH
- 2gH = u^2/2 - u^2/6 = u^2(3-1)/6 = u^2/3
- H = u^2 / (6g)

คำตอบ: จุด A อยู่สูงจากพื้นระดับ = u^2 / (6g)
