ข้อมูลต่อไปนี้คือเฉลยจากสูตรฟิสิกส์โพรเจคไทล์:

**ข้อมูลที่กำหนด:**
- ความเร็วต้น = u, ทำมุม 45° กับแนวดิ่ง → มุมกับแนวราบ = 45°
- ที่จุด A: เวกเตอร์ความเร็วทำมุม 60° กับแนวดิ่ง → มุมกับแนวราบ = 30°
- g = ความเร่งโน้มถ่วง

**วิเคราะห์:**

ขั้นตอนที่ 1: หาองค์ประกอบความเร็ว
- ux = u sin(45°) = u/√2  (ความเร็วแนวราบ — คงที่ตลอดการเคลื่อนที่)
- uy = u cos(45°) = u/√2  (ความเร็วแนวดิ่งเริ่มต้น — ขึ้น)

ขั้นตอนที่ 2: ที่จุด A มุมกับแนวดิ่ง = 60°
- vx_A = ux = u/√2  (ไม่เปลี่ยน เพราะไม่มีแรงในแนวราบ)
- tan(60°) = vx_A / vy_A
  → vy_A = vx_A / tan(60°) = (u/√2) / √3 = u/(√6)

ขั้นตอนที่ 3: ใช้สมการ v² = u² - 2gh (แนวดิ่ง ขาขึ้น)
- vy_A² = uy² - 2gH
- (u/√6)² = (u/√2)² - 2gH
- u²/6 = u²/2 - 2gH
- 2gH = u²/2 - u²/6 = u²(3-1)/6 = u²/3
- H = u²/(6g)

**คำตอบ:**
จุด A อยู่สูงจากพื้นระดับ = u²/(6g)
